# deltafold

deltafold is a planned TypeScript library for modeling version history and
resolving migration instructions between versions. It targets Effect 4.

The package has no public API yet, and no release has been published. See the
[repository](https://github.com/YLfjuk/deltafold) for the design notes and progress.
