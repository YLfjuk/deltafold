# Security policy

## Supported versions

Security fixes target the latest published versions of `deltafold` and
`@deltafold/release`. Earlier versions do not receive backported fixes.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's private vulnerability
reporting. Open the repository's **Security** tab, go to **Advisories**, and
select **Report a vulnerability**. Do not open a public issue, pull request, or
discussion for a suspected vulnerability.

Include the affected version or commit, a description of the impact, and steps or
code that reproduce the problem. Reports are handled on a best-effort basis by
the maintainer. Disclosure is coordinated through the advisory.
