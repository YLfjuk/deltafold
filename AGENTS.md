# Public repository hygiene

- Keep tracked files focused on public project requirements and implementation.
- Never commit private conversation/thread links, session/project identifiers,
  absolute machine paths, personal email addresses, credentials, or local
  orchestration instructions. Use repository-relative paths.
- Keep private coordination in tool messages or ignored local files.
- Use the repository owner's GitHub noreply address for author and committer
  metadata. Do not fall back to a personal email from global Git configuration.
- Before pushing, inspect staged files and commit metadata for privacy leaks.
- Requirements, decisions, and tooling notes live in notes/, and reference
  images in notes/assets/.
